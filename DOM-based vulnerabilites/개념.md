# DOM-based vulnerabilities

## DOM
DOM이란 웹페이지의 요소들을 브라우저가 트리 형태로 파싱한 계층적 구조이다. 자바스크립트는 DOM 객체에 접근하여 페이지를 동적으로 조작할 수 있다.

## Source
공격자가 제어할 수 있는 데이터를 받아들이는 자바스크립트의 속성
ex)
- document.URL
- document.documentURI
- document.URLUnencoded
- document.baseURI
- location
- document.cookie
- document.referrer
- window.name
- history.pushState()
- history.replaceState()
- localStorage
- sessionStorage
- IndexedDB (mozIndexedDB, webkitIndexedDB, msIndexedDB)
- Database

## Sink
Source로부터의 값을 안전하지 않은 방식으로 전달받아 처리할 때 원치 않는 결과를 초래할 잠재성이 있는 자바스크립트 함수 혹은 DOM 객체.
ex)
- document.write() : DOM XSS
- window.location : Open Redirection
- document.cookie : 쿠키 조작
- eval() : JavaScript Injection
- document.domain : Document Domain Manipulation
- WebSocket() : WebSocket URL Poisoning
- (element).src : Src Link Manipulation
- postMessage() : Web Message Manipulation
- setRequestHeader() : Ajax Request Header Manipulation
- FileReader.readAsText() : File Path Manipulation
- executeSql() : Client-Side SQL Injection
- sessionStorage.setItem() : HTML5 Storage Manipulation
- document.evaluate() : Client-Side XPath Injection
- JSON.parse() : Client-Side JSON Injection
- (element).setAttribute() : DOM Data Manipulation
- RegExp() : Denial of Service (ReDoS)

## 방지
- 신뢰할 수 없는 출처의 입력값으로 동적인 응답 및 HTML을 직접 생성하지 않는 것이 가장 좋습니다.
- 동적 처리가 불가피할 경우, 안전한 API(`textContent`, `innerText` 등)를 사용하거나 클라이언트 측 Context에 맞게 HTML Entity Encoding 및 JS Escaping을 적용해야 합니다.
- 필요한 경우 `DOMPurify`와 같은 검증된 새니타이징 라이브러리를 활용합니다.
