# 🛡️ CSRF 방어 기법 정리

## 1. 자격 증명 보호

### 
* `프로필 및 응답`을 통한 `사용자 정보 노출`(이메일, ID등)을 방지해야 한다.
* 인증 정보가 포함된 요청을 처리할 때에 `HTTPS`를 강제해야한다. HTTP 요청시에는 리디렉션 처리를 하자.<br>

## 2. 안전한 비밀번호 설정 강제

### 
* `zxcvbn`같은 자바스크립트 라이브러리를 활용해 비밀번호의 보안 강도를 검증하고 피드백을 제공하는등 안전한 비밀번호 설정을 강제한다.

## 3. Enumeration 방지

### 
* 존재 여부와 무관하게 동일한 오류 메시지, HTTP 상태코드, 균일한 응답 시간 유지를 통해 Enumeration attack을 방지한다.


## 4. Brute-force 공격 방어

### 
* IP기반 접속 제한
* 공격자 IP 조작 방지
* 일정 횟수 실패시 `CAPTCHA` 도입


## 5. 검증 로직 및 보조 기능 점검

### 
* 인증 관련 검증 로직을 철저히 감사하자.
* 비밀번호 재설정/찾기등 보조 기능에도 본 메커니즘 수준의 보안을 적용한다.

## 6. 올바른 Multi Factor Authentication(MFA) 적용

### 
* SMS 2FA(SIM 복제 위험)나 이메일 인증 코드는 피한다. *[이메일은 MITM에 취약하고, 이메일 계정에 같은 기기 및 동일한 브라우저 세션으로 접근하는 경우가 많아, 사실상 단일 인증에 가깝다.]*
* 전용 기기/인증 앱을 사용하자.
